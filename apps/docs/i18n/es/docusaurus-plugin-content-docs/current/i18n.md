# Idiomas y textos

Se incluyen tres idiomas: `en`, `pt-BR` y `es`.

## Elegir un idioma

```tsx
<OfflineDetector locale="es">
  <App />
</OfflineDetector>
```

En web decide la prop `locale`, y se usa `en` cuando no se indica. En nativo la prop `locale`
prevalece y, sin ella, se usa el idioma del dispositivo. Cualquier valor desconocido se resuelve a
`en`. El resolvedor nunca lanza un error:

```ts
import { resolveLocale } from '@rogeriodocarmo/offline-detector-web'; // or -native

resolveLocale('pt-PT'); // 'pt-BR'
resolveLocale('es-MX'); // 'es'
resolveLocale('fr'); // 'en'
```

Cualquier variante de `pt` da `pt-BR`, cualquier `es-*` da `es`, y todo lo demás da `en`.

## Los textos

| Clave                     | en                                   | pt-BR                                          | es                                             |
| ------------------------- | ------------------------------------ | ---------------------------------------------- | ---------------------------------------------- |
| `offline`                 | No internet                          | Sem internet                                   | Sin internet                                   |
| `offlineNoInterface`      | No network connection                | Sem conexão com a rede                         | Sin conexión de red                            |
| `offlineNoInternet`       | Connected, but no internet           | Conectado, mas sem internet                    | Conectado, pero sin internet                   |
| `online`                  | Back online                          | Conexão restabelecida                          | Conexión restablecida                          |
| `retry`                   | Retry                                | Tentar novamente                               | Reintentar                                     |
| `checking`                | Checking…                            | Verificando…                                   | Verificando…                                   |
| `continueOffline`         | Continue offline                     | Continuar offline                              | Continuar sin conexión                         |
| `dismiss`                 | Dismiss                              | Fechar                                         | Cerrar                                         |
| `dismissHint`             | Swipe left or right to dismiss       | Deslize para a esquerda ou direita para fechar | Desliza a izquierda o a derecha para descartar |
| `indicatorLabelOnline`    | Online                               | Online                                         | En línea                                       |
| `indicatorLabelOffline`   | No internet                          | Sem internet                                   | Sin internet                                   |
| `indicatorLabelChecking`  | Checking connection                  | Verificando conexão                            | Verificando conexión                           |
| `indicatorAccessibleName` | Connection status: {status}          | Status da conexão: {status}                    | Estado de la conexión: {status}                |
| `fullScreenTitle`         | No internet                          | Sem internet                                   | Sin internet                                   |
| `fullScreenBody`          | Check your connection and try again. | Verifique sua conexão e tente novamente.       | Revisa tu conexión e inténtalo de nuevo.       |
| `fullScreenRetry`         | Try again                            | Tentar novamente                               | Intentar de nuevo                              |

`{status}` se sustituye por el texto `indicatorLabel*` correspondiente.

## Sobrescribir textos

Pasa un objeto parcial. Cada clave que indiques prevalece sobre el texto del idioma; las demás se
mantienen.

```tsx
<OfflineDetector
  locale="es"
  strings={{ offline: 'Estás sin conexión', retry: 'Otra vez' }}
>
  <App />
</OfflineDetector>
```

La misma combinación está disponible como función. Estos auxiliares, y `resolveLocale` más arriba,
los exportan `@rogeriodocarmo/offline-detector-web` y `@rogeriodocarmo/offline-detector-native`,
así que un solo paquete basta para importarlos:

```ts
import {
  resolveStrings,
  offlineMessage,
  indicatorName,
} from '@rogeriodocarmo/offline-detector-web'; // or -native

const strings = resolveStrings('es', { retry: 'Otra vez' });
offlineMessage(state, strings); // 'Sin internet' (siempre, por defecto)
offlineMessage(state, strings, true); // consciente del motivo: 'Sin conexión de red' o 'Conectado, pero sin internet'
indicatorName(strings, strings.indicatorLabelOffline); // 'Estado de la conexión: Sin internet'
```

Una sobrescritura igual a `undefined` se ignora, y una cadena vacía se conserva. `indicatorName` trata
la etiqueta como texto simple.

## Mensajes que dicen el motivo

Por defecto, todo mensaje de desconexión es `offline`. Con `distinguishReason`, el mensaje pasa a ser
`offlineNoInterface` cuando el motivo es `no-interface` y `offlineNoInternet` cuando es
`no-internet`. El cuerpo de la pantalla completa no cambia. El título de la pantalla completa es
`fullScreenTitle`, en web y en nativo, salvo que `distinguishReason` esté activado: entonces es el
mensaje que depende del motivo.

## Añadir un idioma

Las tablas incluidas cubren tres idiomas. Para otro idioma, pasa un objeto `strings` completo, o las
claves que necesites, junto con el `locale` incluido más cercano.

## Sobre esta documentación

Esta documentación está disponible en los mismos tres idiomas. Las traducciones se hicieron con
cuidado, pero aún necesitan la revisión de hablantes nativos.
