# Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the `offline-detector` pnpm monorepo: workspace, test runner, lint/format/hooks,
four buildable package skeletons, Turborepo, and the CI/Dependabot/Changesets skeleton, all
verified by repo-config tests.

**Architecture:** Root pnpm workspace (`packages/*`, `apps/*`) orchestrated by Turborepo. Each
package builds with Rslib to ESM + CJS + `.d.ts`. Tooling and quality config is ported from
`C:\Github\morse_app` so both repos read as one author's work. Repo configuration is itself
tested (meta-tests), the way `morse_app` tests its CI files.

**Tech Stack:** pnpm 10, Node 24 (`.nvmrc`), TypeScript (strict), Turborepo, Rslib (Rspack), Jest +
`@swc/jest`, fast-check, ESLint flat config + typescript-eslint, Prettier, markdownlint-cli2, Husky,
lint-staged, Changesets, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-07-offline-detector-design.md`

## Global Constraints

- Package names: `@rogeriodocarmo/offline-detector-{core,react,web,native}`; license MIT, holder
  "Rogério do Carmo", year 2026.
- Node `24.15.0` (`.nvmrc`); `packageManager` is `pnpm@10.x`.
- Prettier values identical to `morse_app`: `semi: true`, `singleQuote: true`,
  `trailingComma: "all"`, `printWidth: 90`, `tabWidth: 2`, `arrowParens: "always"`.
- Coverage threshold: 80% global (branches, functions, lines, statements).
- Git Flow: work on `feature/*` branched from `develop`; PRs target `develop`; `main` only receives
  merges from `develop`. **Never rebase**; merge `develop` into the branch instead.
- Dependabot: `target-branch: develop`, weekly, npm + github-actions.
- No network side effects (repo creation, pushing, enabling CodeQL/Pages) without the owner's
  explicit go-ahead. Task 4 marks the gated steps.
- No custom native code anywhere in the repo.

## Review Focus

- Line endings on Windows: files written CRLF break Prettier and shell hooks. Expect `.gitattributes`
  forcing LF and a test that pins it.
- A fresh clone without a committed `pnpm-lock.yaml` breaks `pnpm install --frozen-lockfile` in CI.
  Expect the lockfile committed and a test asserting it exists.
- Husky hooks silently absent after clone. Expect `prepare: "husky"` and a test pinning it.
- Dual-package hazard: a CJS `require` consumer must resolve types and a `.cjs` entry. Expect the
  `exports` map tested and the real build output checked for the files it names.
- Skeleton packages leaking runtime dependencies into consumers. Expect a test that
  `dependencies` is undefined on each package.
- Dependabot opening PRs that bump the Expo/React Native family one package at a time. Expect the
  ignore list tested.

const root = join(__dirname, '..');

    branches: [main, develop]
  pull_request:

concurrency:
  group: ci-${{ github.ref }}

jobs:
  verify:
    name: Build, lint, typecheck and test
    runs-on: ubuntu-latest
    timeout-minutes: 20
    steps:
      - uses: actions/checkout@v4
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v4
        with:
          node-version-file: .nvmrc
          cache: pnpm

      - run: pnpm build
      - run: pnpm typecheck
      - run: pnpm lint
      - run: pnpm format:check
      - run: pnpm lint:md
      - run: pnpm test:ci
      - uses: actions/upload-artifact@v4
        if: always()
        with:
          name: coverage
          path: coverage
          if-no-files-found: ignore
