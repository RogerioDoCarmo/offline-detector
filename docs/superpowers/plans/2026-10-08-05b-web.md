# Plan 5b: web UI layer (phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `packages/web` building blocks (adapter, probe fetch, swipe hook, tokens, four
presentational pieces) that phase 2 wires to the React provider.

**Architecture:** Plain React 18+ function components styled by one CSS string (custom properties
`--od-*`, no CSS-in-JS, no CDN, no fonts) injected through an SSR-safe `<style>` component. Pieces
are props-driven and typed against local copies of the contract types (`src/contract-types.ts`),
so nothing imports runtime code from `@rogeriodocarmo/offline-detector-react`.

**Tech Stack:** React 19 (dev), TypeScript, Jest 30 + jsdom, Testing Library, axe-core, Playwright
(system Chrome only).

**Spec:** `docs/superpowers/specs/2026-10-08-ui-layer-contract.md` (sections 1, 3, 5),
`docs/design/*.md`, `docs/design/prototype.html`.

## Global Constraints

- Importing the package never touches `window` or `document` (SSR-safe).
- `role="status"` for live pieces, never `role="alert"`; `aria-label` only on naming-capable roles.
- Interactive targets are at least 44x44; logical CSS properties only (RTL).
- Swipe: 30% of width, 0.5 px/ms, 8 px axis lock, `touch-action: pan-y`.
- Checking visual: shown after 150 ms pending, kept for at least 400 ms.
- Owns only `packages/web/**`, `e2e/web-ui*` and this plan. Coverage at 95% lines and branches.
- Babel 8 under Jest: no explicit type arguments on calls or `new` in code that Jest compiles.

## Review Focus

- Retry inside a swipeable piece must still work (no pointer capture before the axis lock).
- A tap with under 8 px of movement must neither drag nor dismiss, however fast.
- A vertical drag must never move the piece, even if it later drifts sideways.
- Two foreground signals (visibilitychange and focus) for one return give one callback.
- `FullScreen` removal restores every `inert` / `aria-hidden` it set, including prior values.
- `visible={false}` pieces keep their DOM during exit and ignore input; unmount clears timers.

## File structure (all under `packages/web/src`)

- `contract-types.ts`: local structural copies of the contract types (phase 2 swaps them).
- `adapter.ts`: `createWebAdapter`. `probe-fetch.ts`: `createWebProbeFetch`.
- `swipe.ts`: `useSwipeDismiss` and the pure `lockAxis` / `shouldDismiss` rules.
- `tokens.ts`: `offlineTokensCss`, `offlineCss`, `OfflineTokens`. `styles.ts`: piece CSS.
- `hooks.ts`: `useSettledChecking` (150/400), `useReducedMotion`, `usePublishHeight`,
  `useInteraction`.
- `icons.tsx`, `piece-types.ts`, `snackbar.tsx`, `banner.tsx`, `indicator.tsx`, `fullscreen.tsx`.
- `index.ts`: public exports, keeps `packageName`.

## Tasks (each one: failing test, run, minimal code, run, commit)

1. **Setup**: devDependencies, jsdom environment, jest-dom setup, `contract-types.ts`.
2. **Adapter**: interface up, de-duplicated interface events, one callback per foreground return,
   inert SSR adapter.
3. **Probe fetch**: `no-cors` + `no-store`, opaque counts as success, rejection propagates.
4. **Swipe**: pure rules at 29/30 percent, 0.49/0.5 px/ms, 7/8 px; the hook with synthetic pointer
   events; vertical ignored; spring back; reduced motion; keys; click suppression.
5. **Tokens**: literal values for light and dark (media query and `data-od-theme`), SSR render.
6. **Hooks**: `useSettledChecking` with fake timers, `useReducedMotion`, `usePublishHeight`.
7. **Pieces**: roles and names, dismiss paths, checking state, overrides, axe, SSR render.
8. **E2E**: `e2e/web-ui.spec.ts` with a bundled fixture page (offline, snackbar and banner, swipe
   dismiss, back online, axe). Runs through system Chrome only.
9. **Gate**: typecheck, typecheck:tests, lint, format:check, lint:md, build, `CI=1 pnpm test:ci`.

- **E2E (new):** `e2e/web-ui.spec.ts` with the fixture under `e2e/web-ui-fixture/`.
- **Mutation:** not required for UI packages.
- **Existing tests disturbed:** `packages/web/src/index.test.ts` now asserts the export list;

  `@jest-environment node` docblock. Root meta-tests in `tests/` are not edited; if one breaks it
  is reported instead.
