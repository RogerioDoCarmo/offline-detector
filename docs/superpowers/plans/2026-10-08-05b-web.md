# Plan 5b: web UI layer (phase 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `packages/web` building blocks (adapter, probe fetch, swipe hook, tokens, four presentational pieces) that phase 2 wires to the React provider.

**Architecture:** Plain React 18+ function components styled by one CSS string (custom properties `--od-*`, no CSS-in-JS, no CDN, no fonts) injected through an SSR-safe `<style>` component. Pieces are props-driven and structurally typed against local copies of the contract types (`src/contract-types.ts`), so nothing imports runtime code from `@rogeriodocarmo/offline-detector-react`.

**Tech Stack:** React 19 (dev), TypeScript, Jest 30 + jsdom, Testing Library, axe-core, Playwright (system Chrome only).

**Spec:** `docs/superpowers/specs/2026-10-08-ui-layer-contract.md` (sections 1, 3, 5), `docs/design/*.md`, `docs/design/prototype.html`.

## Global Constraints

- Importing the package never touches `window` or `document` (SSR-safe).
- `role="status"` for live pieces, never `role="alert"`; `aria-label` only on naming-capable roles.
- Interactive targets are at least 44x44; logical CSS properties only (RTL).
- Swipe: 30% of width, 0.5 px/ms, 8 px axis lock, `touch-action: pan-y`.
- Checking visual: shown after 150 ms pending, kept for at least 400 ms.
- Owns only `packages/web/**`, `e2e/web-ui*` and this plan. Coverage of `packages/web` at 95% lines and branches.

## Review Focus

- Click on Retry inside a swipeable piece must still work (no pointer capture before the axis lock).
- A tap with tiny movement (under 8 px) must neither drag nor dismiss.
- A vertical drag must never move the piece.
- Two foreground signals (visibilitychange + focus) for one return give one callback.
- `FullScreen` unmount restores every `inert`/`aria-hidden` it set, including a pre-existing `aria-hidden`.
- `visible={false}` pieces keep their DOM during exit; unmount cleans timers.

## Tasks (each one: failing test, run, minimal code, run, commit)

1. **Setup**: devDependencies, jsdom environment, jest-dom setup, `contract-types.ts`.
2. **Adapter**: interface up, interface events (de-duplicated), foreground (one callback per return), inert SSR adapter.
3. **Probe fetch**: `no-cors` + `no-store`, opaque counts as success, rejection propagates.
4. **Swipe**: pure rules at 29/30 percent, 0.49/0.5 px/ms, 7/8 px; hook with synthetic pointer events; vertical ignored; spring back; reduced motion; keys; click suppression.
5. **Tokens**: literal values for light, dark (media, `data-od-theme`), SSR render, nonce.
6. **Hooks**: `useSettledChecking` with fake timers; `useReducedMotion`; `usePublishHeight`.
7. **Snackbar, Banner, Indicator, FullScreen**: ARIA, roles, dismiss paths, checking state, icons/className overrides, `render` override, axe.
8. **E2E**: bundled fixture page (`e2e/web-ui-fixture/`), `e2e/web-ui.spec.ts` (offline, swipe dismiss, back online, axe). Runs only if a system Chrome is available.
9. **Gate**: typecheck, typecheck:tests, lint, format:check, lint:md, build, `CI=1 pnpm test:ci`.
