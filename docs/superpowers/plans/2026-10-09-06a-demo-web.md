# Plan 6a: web demo (`apps/demo-web`)

Contract: `docs/superpowers/specs/2026-10-09-plan-6-apps-contract.md`. Goal: a Next.js App Router
static export, `basePath` `/offline-detector/demo`, that mounts `<OfflineDetector>` from
`@rogeriodocarmo/offline-detector-web` with a control for every public option, a stub probe that
works without the network, a `useRecheckOnReturn` screen and a slots example.

## Design decisions

- Next 16 builds with Turbopack by default (`next build`), so no flag and no custom webpack.
  `output: 'export'`, `trailingSlash: true` (every route is `index.html`, which any static host and
  the dependency-free test server serve), `images.unoptimized`.
- Workspace packages are consumed through `exports`/`dist` (`workspace:*`), no `transpilePackages`
  and no aliases. A `'use client'` demo component is the only client boundary; `page.tsx` is a
  server component, so the static HTML is rendered on the server and hydrated.
- Simulation never touches the network. A demo controller owns two switches: the stub probe
  (`fetch` prop) answers ok or fails, and a wrapped web adapter can report the interface as down.
  Real offline (DevTools, `goOffline()`) still works because the wrapped adapter defers to the
  real `navigator.onLine` and `online`/`offline` events.
- `probe`, `initialStatus` and `fetch` are read once per mount, so changing them remounts the
  detector (a `key`).
- No fonts or assets are fetched: system font stack, inline-free CSS file, no CDN.
- Accessibility: labelled controls (`fieldset`/`legend`, `label`), visible focus ring, AA colours
  in light and dark through `prefers-color-scheme` custom properties, a skip-free single `main`.

## Tasks

1. Scaffold `apps/demo-web` (package.json, tsconfig, next.config.ts, layout, CSS).
2. Demo controller + stub (`lib/controller.ts`), options model (`lib/options.ts`).
3. Components: control panel, status readout, event log, recheck screen, custom slot.
4. E2E serve script for `out/` under the base path; `playwright.config.ts` second web server.
5. `e2e/demo-web.spec.ts`; `tests/demo-web.test.ts`; README; gates.

## Tests

- Unit (Jest): `tests/demo-web.test.ts` is a meta-test only (the app is excluded from coverage):
  `output: 'export'`, the `basePath` literal, `trailingSlash`, workspace deps, scripts
  (`build` = `next build`, no `--webpack`), React 19 + Next 16, the Playwright server entry and the
  serve script. Existing tests: none disturbed (`workspace.test.ts` already expects `apps/*`).
- Property: none; no new pure logic with an invariant (controller is trivial plumbing).
- E2E (Playwright, `e2e/demo-web.spec.ts`, against `apps/demo-web/out`): online shows nothing;
  Simulate Offline shows snackbar, banner and indicator with "No internet"; pt-BR and es literal
  strings from `docs/design/strings.md`; swipe-dismiss then pieces return on the next transition;
  Retry; fullScreen opt-in with Continue offline; real `goOffline()`; `distinguishReason`; slots;
  recheck screen; axe on each state in light and dark.
  Existing `smoke.spec.ts` and `web-ui.spec.ts` keep their server (port 4173) untouched.
- Mutation: Stryker is scoped to `packages/*` source; the demo is out of scope, nothing to add.
