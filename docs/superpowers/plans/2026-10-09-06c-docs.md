# Docs Site Implementation Plan (Plan 6c)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Docusaurus site for the four packages in English, Brazilian Portuguese and Spanish,
published together with the web demo as one GitHub Pages site built by Actions.

**Architecture:** `apps/docs` (`@offline-detector/docs`, private) is a Docusaurus 3 classic site with
`baseUrl` `/offline-detector/`, no search plugin, no analytics, no remote fonts and nothing fetched
at build time. Docs live under `/docs/`; a custom landing page carries the brand layer of
`DESIGN.md`. `.github/workflows/pages.yml` builds docs and (when present) the demo, assembles one
site with `apps/docs/scripts/assemble-site.cjs`, and deploys only from `main` and manual dispatch.

**Tech Stack:** Docusaurus 3.10, React 19, TypeScript, GitHub Actions Pages.

**Spec:** `docs/superpowers/specs/2026-10-09-plan-6-apps-contract.md` (binding), `DESIGN.md` (brand
layer), `docs/design/*`.

## Global Constraints

- Document only what the packages really export. Each reference page ends in an export index
  (heading id `export-index`) whose names must equal the package's `src/index.ts` exports.
- Every English page exists in `pt-BR` and `es` with the same structure. Translations are real, and
  the README says a native-speaker review is still needed.
- Brand colours only in `apps/docs/src/css/custom.css`, every text pairing AA, computed by
  `apps/docs/scripts/contrast.cjs`.
- Broken links throw. Links to the live demo use the absolute URL because the demo is not a
  Docusaurus route.
- Never enable Pages; the owner does (`docs/OWNER-ACTIONS.md`).

## File Structure

- `apps/docs/{package.json,docusaurus.config.ts,sidebars.ts,tsconfig.json,README.md}`
- `apps/docs/docs/**` (English), `apps/docs/i18n/{pt-BR,es}/**` (translations and UI strings)
- `apps/docs/src/{css/custom.css,pages/index.tsx,components/SignalArc.tsx}`, `static/img/*`
- `apps/docs/scripts/{contrast.cjs,assemble-site.cjs}`
- `.github/workflows/pages.yml`, `docs/OWNER-ACTIONS.md` (Pages section)
- `tests/docs.test.ts`

## Tests

All in the new `tests/docs.test.ts`, literal expectations.

- **Unit / meta:** Docusaurus config (`url`, `baseUrl`, `onBrokenLinks: 'throw'`, locales, default
  locale, no remote scripts or fonts); every English doc exists in `pt-BR` and `es`; the export
  index of each reference page equals the real export list of the package; every page links the
  demo; the privacy page names both default probe URLs; the contrast table (12 literal ratios) and
  that `custom.css` uses exactly those colours; `assemble-site.cjs` run against temporary folders
  (with demo and privacy policy, without either); `pages.yml` triggers, permissions, deploy-only
  on `main`, build-only on pull requests, demo step condition; OWNER-ACTIONS Pages section.
- **Property:** not applicable (no logic beyond the ratio function, covered by literal cases).
- **E2E:** not applicable: no Playwright project targets the docs; the build with broken links set
  to throw is the integration check. Reported as not run in a browser.
- **Mutation:** apps are outside the Stryker scope.
- **Existing tests disturbed:** none edited. `tests/workspace.test.ts` and `tests/ci-config.test.ts`
  were read; the new app adds a workspace package only.
