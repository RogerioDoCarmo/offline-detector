# W2 web: final-review fixes

Contract: `docs/superpowers/specs/2026-10-09-final-review-fixes.md`, section "W2: web". Branch
`fix/web`. Each item is test first: the whole multi-step sequence, watched failing for the right
reason, then the fix.

## Order

1. Web probe fetch: `credentials: 'omit'`, `referrerPolicy: 'no-referrer'`, result returned as is.
2. A-M7: the adapter ignores focus moves into an iframe.
3. A-I3, A-M4: the swipe gesture ends on a window `pointerup` / `pointercancel` or a move with no
   buttons; a dismissal started in one status never lands in the next one.
4. A-I8: `:where(:root)` tokens; `nonce` through `<OfflineDetector>`.
5. A-I1: live regions mount empty, the text arrives a frame later.
6. A-I7: focus returns to the element that had it before the piece appeared.
7. A-M10: FullScreen under StrictMode, and elements added after mount.
8. A-M6: indicator name replaces every occurrence, literally.
9. API: unexport internals, `onContinueOffline`, `fullScreenTitle`, re-exports, piece-types comment.
10. README, storybook-web, demo-web, e2e.
